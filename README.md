👉 Pandas DataFrame
🔹 DataFrame Concept

A Pandas DataFrame is a 2-dimensional, tabular data structure with rows and columns, similar to an Excel spreadsheet or SQL table.
Each column can store different data types such as numbers, strings, or dates.

Key Characteristics:

Labeled rows (index) and columns

Size-mutable (rows/columns can be added or removed)

Supports powerful data manipulation and analysis
