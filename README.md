## ▶️ How to Run (Google Colab)
1. Open **Google Colab**
2. Upload the `.ipynb` file from this repository  
   **OR**
3. Open directly from GitHub:
   - Go to the notebook file
   - Click **Open in Colab**
4. Run cells one by one

> No installation needed – Matplotlib comes pre-installed in Colab ✅
